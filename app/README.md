# Finansovik

Telegram-бот із командами `/start`, `/help` та `/expense`.

## Додавання витрати

Натисніть кнопку **Витрати**, а потім напишіть суму й категорію, наприклад `120 кава`.
Або надішліть команду `/expense 120 кава` чи `/expense 85,50 продукти`.
Щоб скасувати введення після натискання кнопки, надішліть `/cancel`.
Сума має бути більшою за нуль, із не більше ніж двома знаками після коми.
Категорії створюються окремо для кожного користувача; однакова назва використовується повторно.

Перед першим використанням створіть таблиці в базі командою з теки `app`:

```powershell
.\.venv\Scripts\python.exe database.py
```

Команда створює відсутні таблиці `users`, `categories`, `transactions` та `incomes` і не змінює вже наявні.

## Перевірка підключення до бази даних

Додайте `DATABASE_URL` до файлу `app/.env`. У PowerShell із теки `app` виконайте:

```powershell
.\.venv\Scripts\python.exe -m pip install -r requirements.txt
.\.venv\Scripts\python.exe check_db.py
```

`OK` означає, що підключення та запит `SELECT 1` виконалися успішно. `NOT OK` означає, що перевірка не вдалася.

## Отримання транзакцій

Запустіть фронтенд і API разом з теки `app`:

```powershell
docker compose up --build frontend api
```

Після запуску відкрийте **http://localhost:5173**. Сторінка отримує дані з `/api/summary` та
`/api/transaction`; якщо один із запитів не вдався, його можна повторити кнопкою на сторінці.
Зупиніть сервіси через `Ctrl+C` у терміналі. Для цього запуску Node.js на комп'ютер встановлювати не потрібно.

Щоб запустити лише API, виконайте:

```powershell
docker compose up --build api
```

`GET http://127.0.0.1:8080/api/transaction` повертає JSON-масив доходів і витрат із Neon,
від нових до старих. Кожен запис містить `id`, `type`, `user_id`, `category_id`, `category`,
`amount` (рядок із сумою без втрати точності), `date` (дата операції) та `created_at` (час створення запису).
Якщо записів немає, відповідь — `[]`. Якщо база недоступна, API повертає помилку HTTP 503.

API призначене лише для локальної розробки: авторизації та розмежування користувачів поки немає,
тому запит повертає транзакції всіх користувачів. Не відкривайте його в інтернет до додавання захисту.

## Підсумок доходів і витрат

`GET http://127.0.0.1:8080/api/summary` повертає JSON-об'єкт із полями `total_incom`
(сума доходів), `total_expense` (сума витрат) і `balance` (доходи мінус витрати).
Суми передаються рядками з двома знаками після коми. Якщо записів немає, суми дорівнюють `0.00`.
Як і список транзакцій, підсумок поки охоплює всіх користувачів і доступний без авторизації.
Дохід можна додати через вебформу; команди додавання доходу в боті поки немає.

## Додавання транзакції з вебформи

Для наявної бази один раз виконайте міграцію з теки `app`:

```powershell
.\.venv\Scripts\python.exe migrate_web_transactions.py
```

`POST /api/transaction` приймає JSON, наприклад:

```json
{"type":"expense","amount":"39.00","category":"сік","date":"2026-11-23"}
```

`type` — `expense` або `income`, сума невід’ємна, категорія містить літери,
пробіли, дефіс або апостроф. Дата необов’язкова; якщо її не передати, використовується
поточна дата в Києві. Успішне збереження повертає HTTP 201, некоректні дані — HTTP 400.

Авторизації у вебверсії ще немає. Записи з форми належать окремому спільному локальному
вебкористувачу та не прив’язуються автоматично до облікового запису Telegram.

## Видалення транзакції

У таблиці натисніть іконку кошика й підтвердьте видалення. Після успіху список і підсумок оновляться.
API використовує `DELETE /api/transactions/{id}?type=expense` або `?type=income` і повертає
HTTP 204 при успіху, HTTP 404, якщо запис не знайдено, та HTTP 400 при некоректних параметрах.
Тип обов’язковий: дохід і витрата можуть мати однаковий ID у різних таблицях.
